# 逐神之戏 · 规则与参赛者

> **这不是一段背景故事，这是一场比赛。**
> 玩家和十八位英雄都是参赛者，都在往上爬，只有一个人能到顶。

---

## 一、什么是「逐神之戏」

| 项 | 内容 |
|---|---|
| **谁办的** | **教会**（本质上是教皇） |
| **什么时候** | 795 年开始。**前面几批都失败了** |
| **名目** | 「代神选人」—— 谁能走到神位，谁就是下一个神 |
| **实际目的** | **教皇在找一个人，替他放下执念** |
| **场地** | 三幕：**人间 → 伪神国 → 神明之土** |
| **规则** | 只有三条 |

### 三条规则

1. **只有一个人能到顶。**
2. **到顶之前，可以杀任何人。**
3. **死了就是死了 —— 但游灵可以再来。**

> 第三条是教皇加的。因为**规则必须给他自己留后路**。

---

## 二、参赛者是什么

| 项 | 玩家 | 十八位英雄 |
|---|---|---|
| **是什么** | **无名的游灵** | **有名的游灵** |
| **附在谁身上** | **无名的死人**（十六个职业） | **有名的死人**（历史上的英雄） |
| **记得多少** | **不记得** | **全都记得** |
| **为什么参赛** | **不知道**（开局没有理由） | **每个人都有理由** |

**核心差别：**

> **玩家不知道自己为什么在这儿。**
> **英雄们知道得太清楚了。**

这是整场比赛最残忍的地方 ——
玩家是唯一一个**轻装上路**的。

---

## 三、十八位英雄的「参赛理由」

> 这是他们加入逐神之戏的动机。
> 每一句都是他们在游戏里第一次见面时会说的东西。

| 英雄 | 参赛理由 | 他想要的东西 |
|---|---|---|
| **阿喀琉斯** | 被推进来的 | **想输一次。** 他这辈子没输过 |
| **赫克托耳** | 自己走来的 | **想守到有人来。** 上次没人来 |
| **奥德修斯** | 被叫来的 | **想回家。** 但家已经不在了 |
| **赫拉克勒斯** | 被罚来的 | **想做完最后一件。** 然后就不用再做了 |
| **珀尔修斯** | 被派来的 | **想看清自己斩的是什么。** 上次他没看清 |
| **忒修斯** | 继承来的 | **想不再提父亲。** 但所有人都在提 |
| **伊阿宋** | 雇来的 | **想拿回被拿走的东西。** 他不记得是什么了 |
| **俄耳甫斯** | 自愿来的 | **想再看一眼。** 但他知道不能回头 |
| **卡珊德拉** | 自己来的 | **想被人相信一次。** 一次就够 |
| **美狄亚** | 被逼来的 | **想算清最后一笔账** |
| **阿塔兰忒** | 跟着来的 | **想回到有风的地方** |
| **普罗米修斯** | 被押来的 | **想看看火最后烧成什么样** |
| **西西弗斯** | 被安排来的 | **想把那段墙修完** |
| **齐格弗里德** | 被抹名后回来的 | **想让人记住是他按住的** |
| **布伦希尔德** | 被忘掉后回来的 | **想有人记得那座城门** |
| **洛基** | 混进来的 | **想看看最后谁笑** |
| **海姆达尔** | 来报信的 | **想说第八次「我看见了」** |
| **提尔** | 来要回手的 | **想再签一次约** |

## 四、他们在三幕里是什么样

> 对应代码里的 `desc`（第一幕）/ `desc3`（第三幕）。
> **中间缺的第二幕，就是他们「变了」的地方。**

### 第一幕 · 人间（还没走远）

| 状态 | 描写方向 |
|---|---|
| **还在装** | 他们还是历史上那个样子。**说话有架子** |
| **还没认清** | 以为自己能赢 |
| **对玩家** | 客气、试探、或者直接动手 |

### 第二幕 · 伪神国（开始被消耗）

| 状态 | 描写方向 |
|---|---|
| **开始露底** | 他们的关键词**翻面了** —— 骄傲的露出悔过，守城的开始想走 |
| **开始死人** | **十八个里会死掉一批。** 玩家看到的是他们死的样子 |
| **对玩家** | 有的人开始跟着玩家，有的人开始恨玩家 |

### 第三幕 · 神明之土（只剩一个念头）

| 状态 | 描写方向 |
|---|---|
| **只剩一件事** | 每个人只剩一个动作、一句话 |
| **不再解释** | 台词不到十个字 |
| **对玩家** | 要么打，要么托付 |

## 五、英雄与玩家的四种关系

| 关系 | 怎么触发 | 结果 |
|---|---|---|
| **同盟** | 好感足够 / 选择帮他 | 他会跟着你走一段，**给你一个能力** |
| **敌对** | 选择动手 | 打一场。**杀了有奖励，放过他也不一定会感激** |
| **漠然** | 走开 | 他继续自己的路。**可能在你前面** |
| **超越** | 你比他先到 | 他会在下一幕**以另一种方式出现**（通常是尸体或者留言） |

> **关键**：**放过他，不等于他会放过你。**
> 他们也是在比赛。

## 六、每个英雄「在比赛里做的那件事」

> 这一栏可以做成游戏里的「赛况」提示：玩家能看见别人走到哪了。

| 英雄 | 他每一幕在做什么 | 玩家怎么知道 |
|---|---|---|
| **阿喀琉斯** | **一直在最前面** | NPC 会说「那个拿剑的已经过了第二道门」 |
| **赫克托耳** | **站在同一个地方不动** | 你走回来他还在 |
| **奥德修斯** | **绕路，比谁都慢** | 但每次都比你先到 |
| **赫拉克勒斯** | **替别人清路** | 路上会有他清过的痕迹 |
| **珀尔修斯** | **在找东西** | 他会问你「你见过一个不像人的东西吗」 |
| **忒修斯** | **在等** | 他一直在同一个门口 |
| **伊阿宋** | **在招人** | 你有机会被他雇 |
| **俄耳甫斯** | **在唱** | 你会听见歌声，越往上越近 |
| **卡珊德拉** | **在说，没人听** | 她的话会以「留言」的形式出现 |
| **美狄亚** | **在算** | 她会记住你欠她的每一笔 |
| **阿塔兰忒** | **在跑** | 你只会看见她经过的痕迹 |
| **普罗米修斯** | **被押着走** | 他一直被锁着，但一直在往上 |
| **西西弗斯** | **在原地** | 他修的那段墙，你可以帮他，也可以踢倒 |
| **齐格弗里德** | **在找赫拉尔** | 他一直问「你见过一个姓赫的没有」 |
| **布伦希尔德** | **在守一个没人来的门** | 你路过的时候她在 |
| **洛基** | **在跟所有人开玩笑** | 你分不清他哪句是真的 |
| **海姆达尔** | **在数** | 他会告诉你「这是第几次」 |
| **提尔** | **在谈条件** | 每次见面他都要你签一样东西 |

## 七、比赛的「进度条」怎么给玩家看

三个层次，从粗到细：

| 层次 | 玩家看到什么 |
|---|---|
| **粗** | 地图上偶尔出现**别人走过的痕迹**（脚印、血迹、留言） |
| **中** | 遇到英雄时，他会说「你已经慢了」或者「你在前面」 |
| **细** | **第三幕**，玩家会看到剩下的人还有几个 |

---

## 八、「英雄也会死」

> 这是让比赛真实的关键：**他们会死，而且会死在玩家前面。**

| 死法 | 表现 |
|---|---|
| **被玩家杀** | 有 `kill` 文本，有奖励 |
| **被别人杀** | 玩家会**在路上看见尸体** |
| **自己放弃** | 留下一样东西，人不见了 |
| **走到头** | **极少数**。如果英雄先到顶，那就是玩家的失败结局之一 |

---

## 九、一个可以放进游戏的核心提问

> 玩家在第一幕会听到一句话，来自不同的英雄，说法不同：

| 谁说的 | 怎么说 |
|---|---|
| **阿喀琉斯** | 「你也是被推进来的？」 |
| **赫克托耳** | 「你守什么？」 |
| **奥德修斯** | 「你要换什么？」 |
| **卡珊德拉** | 「你信我吗？」 |
| **提尔** | 「你签不签？」 |

**而到了第三幕，同样的问题变成了：**

| 谁 | 第三幕再问 |
|---|---|
| **阿喀琉斯** | 「你还没输过吗？」 |
| **赫克托耳** | 「你还没走？」 |
| **奥德修斯** | 「你还有什么可换的？」 |
| **卡珊德拉** | 「现在你信了吗？」 |
| **提尔** | 「你签的还在吗？」 |

---

## 十、教皇在这场比赛里的位置

| 项 | 内容 |
|---|---|
| **他是裁判吗** | **不是。** 他是**唯一一个不下场的人** |
| **他在等什么** | **等有人走到他面前** |
| **他为什么办这场比赛** | **因为他一个人放不下** |
| **最终战的那句话** | 「**你替我放下吧。**」 |

> **逐神之戏从头到尾只有两个参赛者：**
> **一个是玩家。一个是教皇。**
> 其余十八个人，都是他们两个人之间的桥。
