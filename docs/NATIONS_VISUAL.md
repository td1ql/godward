# 五国视觉资料 · 服饰 / 建筑 / 武器 / 饮食

> 供美术参考。每个国家一套**材质、颜色、形状规则**。
> 判断标准：**只看一张图，能不能说出这是哪个国家。**

---

## 一、总览对照

| 国 | 主色 | 材质 | 形状 | 一句话 |
|---|---|---|---|---|
| **赫兰** | **灰蓝 + 灰白 + 旧金** | 石、亚麻、旧铜 | **垂直、对称、高** | 一个把秩序盖在废墟上的国 |
| **北马克** | **铁灰 + 雪白 + 暗红** | 粗毛、皮革、生铁 | **横向、低、厚重** | 一个背对着别处的国 |
| **卡斯提** | **赭石 + 青绿 + 铜** | 木材、帆布、铜、玻璃 | **斜、错落、密** | 一个按账本长出来的国 |
| **三渠** | **土黄 + 砖红 + 河绿** | 夯土、陶、木桩 | **圆、拱、层层叠** | 一个在水边讨价还价的国 |
| **无声之地** | **灰白 + 土褐 + 无彩** | 灰、骨、旧布 | **无规则、剥离、残** | 一个没有名字的地方 |

## 二、赫兰（中部平原 · 王权）

### 服制

| 阶层 | 服饰 | 细节 |
|---|---|---|
| **王 / 贵族** | **灰蓝色长袍，外披灰白短斗篷** | 领口一枚**旧金别针**（灰隼形），越旧越有身份 |
| **官吏** | 深灰直领袍，**腰间挂一串木牌** | 木牌数量=品级。走路会响 |
| **军人** | 灰白罩袍 + 鳞甲 | 罩袍下摆**一定有一道泥线**（不洗掉，是资历） |
| **平民** | 亚麻本色，**袖口永远磨损** | 女人用布条束发，男人剃短 |
| **教会（420 后）** | 全黑，**只有领口一道白** | 披肩长度=职级 |

**禁忌**：赫兰人**不戴帽子**。帽子是「要遮住什么」的意思，只有罪犯戴。

### 建筑

| 类型 | 特征 |
|---|---|
| **白塔 / 圣殿** | **91 米，纯白，无装饰，顶上一只眼睛**。越往上越窄 |
| **民居** | 石头地基 + 木架 + **灰泥墙面**，两层，**窗很小**（防冷也防看） |
| **城墙 / 界碑** | **垂直线条为主**，一切都在往高处长 |
| **教堂（420 后）** | **尖拱、飞扶壁、彩色玻璃只在一处**（正对入口的那扇） |

**形状规则**：**垂直、对称、留白多**。赫兰的建筑看起来「空」，因为他们的权力是空的。

### 武器

| 武器 | 说明 |
|---|---|
| **长柄直剑** | 王朝骑士的标准配置。**刃直，没有弧度** |
| **方盾** | 盾面只有一个灰隼纹，没有装饰 |
| **长矛** | 军队制式。矛头是**扁菱形** |

**细节**：赫兰武器的握柄都缠**灰色布条** —— 打仗前要换成新的，打完不换。**布条越脏，资历越老。**

### 饮食

| 项 | 内容 |
|---|---|
| **主食** | 黑麦面包（硬，要泡汤） |
| **常见菜** | 豆子炖咸肉、**腌菜**（冬天唯一有味道的东西） |
| **酒** | 淡啤酒（当水喝）、**少量葡萄酒**（只有节庆） |
| **仪式食品** | **无字饼** —— 葬礼上分给每个来的人，饼上不印任何花纹 |

## 三、北马克（北方 · 领主联盟）

### 服制

| 阶层 | 服饰 | 细节 |
|---|---|---|
| **领主** | **厚重的深色毛皮斗篷**，内衬暗红 | 斗篷**不扣**，用一根骨针别在肩头 |
| **战士** | 皮甲 + 锁子甲，**外层罩粗毛短衣** | 腰间挂**一小袋盐**（不是调味，是防冻伤） |
| **平民** | **所有衣服都不合身**（祖传的，改不了） | 手永远在袖子里 |
| **猎人** | 白色罩衣 + **兜帽压到眉毛** | 长城外行走时**反穿**（白色朝外） |

**特征**：北马克人**全都戴帽子或兜帽**。因为冷，也因为不问名字。

### 建筑

| 类型 | 特征 |
|---|---|
| **长城** | **不是一道墙，是二十二段**，每段一个领主修，**接口处对不齐** |
| **哨塔** | 方形，**低矮**，比墙高不了多少 —— **怕被看见** |
| **民居** | **半地下的石屋**，屋顶压石头，只露一个烟道 |
| **领主厅** | 长条形，**中间一条长火塘**，所有人并排坐着，没有主位 |

**形状规则**：**横向、低、厚重**。北马克的建筑是**趴着的**。

### 武器

| 武器 | 说明 |
|---|---|
| **斧** | 单刃，**斧背带钩**（拖尸体用的） |
| **短矛** | 比赫兰短一半，用于近身 |
| **圆盾** | 木制，**蒙一层皮**，中间一颗铁钉 |
| **刀** | 短、厚、**刃口有锯齿**（不是砍，是锯） |

**细节**：北马克武器的木柄上**刻横线**。刻满一行，就换一根。**没人刻名字。**

### 饮食

| 项 | 内容 |
|---|---|
| **主食** | 燕麦糊、黑面包（更硬，要泡雪水） |
| **常见菜** | 腌鱼、**风干肉**（挂在屋檐下，一挂一整年） |
| **酒** | **烈酒**（用雪水勾兑，度数极高） |
| **仪式食品** | **盐** —— 待客只给一撮盐，意思是「你安全了」 |

## 四、卡斯提（南方海岸 · 商人共和）

### 服制

| 阶层 | 服饰 | 细节 |
|---|---|---|
| **大商人** | **赭石色长外袍 + 青绿内衬**，**袖口有一枚铜环** | 铜环上刻**今年赚了多少**（不刻数字，刻符号） |
| **账房** | 深色短袍，**胸前挂一块木板**（随时记） | 手上永远有墨 |
| **码头工** | 只有一条**帆布围裙**，上身赤裸 | 后背有**绳子的勒痕**（常年拉缆） |
| **女人** | 长裙 + **披肩**，头发盘起来**插一根铜针** | 铜针的粗细=家底 |

**特征**：卡斯提人**都戴手套**（除了码头工）。戴手套是因为**手上不能有墨**。

### 建筑

| 类型 | 特征 |
|---|---|
| **交易所** | **圆形**，中间一个**大铜钟**，四周是柜台 |
| **民居** | **一层商铺 / 二层住人 / 三层仓库**，**颜色各不相同**（谁家有钱谁的墙刷得亮） |
| **港口** | 木栈桥**层层叠叠**，像树根 |
| **教堂** | **很小**，藏在建筑之间 —— 因为「在卡斯提提神是失礼的」 |

**形状规则**：**斜、错落、密**。没有一条直线，全在挤。

### 武器

| 武器 | 说明 |
|---|---|
| **短剑** | 细，**藏在袖子里** |
| **弯刀** | 船上的制式，**刃薄，便于在桅杆间滑动** |
| **钩** | 不是武器，是工具 —— 但卡斯提人用它杀人 |
| **弩** | 港口守卫用，**弩身上刻着船号**（谁的就归谁的） |

**细节**：卡斯提人**不在武器上花钱**。他们的武器都很便宜，因为**他们宁可花钱雇人**。

### 饮食

| 项 | 内容 |
|---|---|
| **主食** | **白面包**（比别国白，是身份的象征） |
| **常见菜** | 海鲜、**橄榄、无花果**、加了香料的炖菜 |
| **酒** | **葡萄酒**（南方产） |
| **仪式食品** | **一枚硬币** —— 签约时双方各咬一下，然后收起来 |

## 五、三渠（东南 · 城邦同盟）

### 服制

| 城市 | 服饰 | 细节 |
|---|---|---|
| **铁桥** | **砖红**短衣 + 长裤，**腰上系绳** | 绳结数=过桥次数 |
| **盐井** | **土黄**长袍，**袖口收紧**（防盐） | 头发用**盐结晶**压平（有钱人才做得到） |
| **断渠** | **河绿**，衣摆**一律裁到膝盖**（方便涉水） | 身上有**水渍的印子**（洗不掉） |

**共同特征**：三渠人**都光脚或穿草鞋**。因为「水边走路，鞋没用」。

### 建筑

| 类型 | 特征 |
|---|---|
| **水坝** | **318 年之后没人敢提**。现在的坝是**补过的**，颜色不一样 |
| **民居** | **夯土墙 + 陶瓦顶**，**房子一层层往上叠**（地不够） |
| **桥** | 铁桥是**石拱桥**，桥面上有**一排小摊** |
| **盐井** | 井口是**圆形**，周围一圈陶罐 |

**形状规则**：**圆、拱、层层叠**。三渠的建筑都是**顺着水势长的**。

### 武器

| 武器 | 说明 |
|---|---|
| **长棍** | 三渠人的主要武器。**便宜、好用、不致命**（他们要活口） |
| **镰** | 农具改的，**刃向内弯** |
| **陶罐** | 装盐的，也可以砸人 |

**细节**：三渠人**不轻易杀人**。他们要的是**让对面服软**，然后收钱。

### 饮食

| 项 | 内容 |
|---|---|
| **主食** | 小米、**河鱼** |
| **常见菜** | **咸得很重**（盐多）、腌菜、**水煮一切** |
| **酒** | **米酒**（浑浊，度数低） |
| **仪式食品** | **一碗河水** —— 结盟时三城各舀一勺倒进一个碗里 |

## 六、无声之地（极西 · 无国家）

### 服制

| 项 | 内容 |
|---|---|
| **所有人** | **没有「服饰」这个概念** —— 有什么穿什么，**全是捡来的** |
| **颜色** | **灰白、土褐、无彩** |
| **特征** | 衣服**缝补过很多次**，补丁用的是不同材质 |
| **不穿** | **不穿任何有标记的东西**（徽章、绳结、颜色） |

**关键**：无声之地的人**不携带任何能证明身份的东西**。因为没有身份。

### 建筑

| 项 | 内容 |
|---|---|
| **有建筑吗** | **几乎没有**。有也只是**临时的** |
| **形式** | 石头围一圈、挖个坑、靠着废墟搭一块布 |
| **特征** | **一推就倒**。因为「住不久」 |
| **唯一的「建筑」** | **西边的边界** —— 但那不是墙，是**没有人再往西走的地方** |

### 武器

| 项 | 内容 |
|---|---|
| **有什么** | 石头、木棍、**骨头** |
| **特征** | **没有一件是「做出来的」**，都是捡的 |

### 饮食

| 项 | 内容 |
|---|---|
| **吃什么** | 什么都能吃。**土、根、皮、虫** |
| **不吃什么** | **不喝西边的水** |
| **仪式** | 没有仪式。**吃饭不是仪式，是活下去** |

## 七、五国视觉速查（给美术的一句话）

| 国 | 一句话 |
|---|---|
| **赫兰** | **白塔、灰袍、垂直线、一切都在往上长** |
| **北马克** | **趴在雪里的方塔、毛皮、横线、所有东西都很重** |
| **卡斯提** | **挤在一起的彩色墙、铜环、手套、到处都是钩子和绳** |
| **三渠** | **挂在河边的土房子、光脚、长棍、陶罐** |
| **无声之地** | **没有房子、没有颜色、没有名字** |

## 八、跨国的共同点（免得画成五个世界）

| 元素 | 全大陆通用 |
|---|---|
| **颜色** | **灰蓝 / 灰白 / 旧金 / 土褐** —— 整体低饱和 |
| **光源** | **逆光 + 侧面单光源**，背景压暗 |
| **材质** | **石、木、麻、铁、骨** —— 没有塑料感 |
| **人物** | **脸要有风霜**，不要干净的脸 |
| **构图** | **人物占画面 1/3~1/2**，留大量暗部 |

> **五个国家是同一个世界的五个角落，不是五个世界。**
