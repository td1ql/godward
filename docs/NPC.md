# 英雄 NPC 写作规范

每个英雄是一个**可反复见面、渐进解锁**的对话角色。框架已经搭好，你只需要往 `scripts/npc_db.gd` 的 `NPCS` 里填文字。

---

## 一、数据结构

```gdscript
"英雄名": {
	"title": "他的称号",                          ← 界面右上角的小字
	"portrait": "res://assets/art/enemy/warden.webp",  ← 立绘（暂时用剪影占位）
	"bond_favor": 45,                            ← 好感多少才能结盟
	"greeting": "他背对着你站在那里。",            ← 刚打开时对话框里的字
	"topics": [ … ],                             ← 话题列表
},
```

---

## 二、话题（topics）

```gdscript
{
	"id": "t1",                       ← 唯一 id，存档里记这个，改 id 会让玩家重聊
	"label": "「你为什么站在这里？」",  ← 按钮上的字（建议整句放在「」里）
	"action": "他一只手按在刀柄上。",   ← 点开时状态行显示的动作
	"text": "他看了你很久。\n「等人。」", ← NPC 说的话，\n 是换行
	"requires": {"topics": ["t0"]},   ← 可选：出现条件
	"responses": [ … ],               ← 必填：玩家可以怎么回答
},
```

### requires 的三种写法

| 写法 | 意思 |
|------|------|
| `{"topics": ["t1"]}` | 聊过 t1 才出现 |
| `{"favor": 20}` | 好感 ≥ 20 才出现 |
| `{"topics": ["t1"], "favor": 20}` | 两个条件都要满足 |

---

## 三、回答（responses）

每个话题 **2~4 条**，让玩家有选择感。

```gdscript
{"label": "「等谁？」", "text": "「一个朋友。」", "favor": 5},
```

| 字段 | 意思 |
|------|------|
| `label` | 玩家说的话（按钮文字） |
| `text` | NPC 听完之后的回应 |
| `favor` | 好感变化，可以是负数 |

**建议写法**：同一个话题的三条回答里
- 一条 **好**（+8 左右）—— 顺着他的话说
- 一条 **更好**（+10~14）—— 说到他心里去
- 一条 **坏**（−2~−5）—— 冒犯他 / 不把他的事当回事

---

## 四、职业专属开场白（vocation_lines）

同一句问话，**不同职业**会得到不同反应。这是让世界「认得你」的关键。

```gdscript
{
	"id": "t1",
	"text": "他看了你很久。\n「等人。」",          ← 默认（职业没写时用这个）
	"vocation_lines": {
		"等待丈夫的新娘": "他看了你很久。\n「你也在等。」\n「那我们是一样的。」",
		"焚书的疯子": "他看了你很久。\n「你身上有烟味。」\n「烧过东西的人，不劝人走。」",
	},
	"responses": [ … ],
},
```

### 16 个职业的 key（必须一字不差）

```
等待丈夫的新娘  失明的守钟人   饥饿的朝圣者   沉默的执剑人
疯癫的先知      褴褛的记账人   断臂的旗手     无名的旅人
溺水的小公主    焚书的疯子     守夜的哨兵     数星星的瞎子
磨刀的哑巴      收尸的妇人     执棋未落的妙手  等死的病人
```

## 五、好感与结盟

- 好感存 `GameState.impressions[英雄名]`，**0~100**
- 每聊一个话题，最多拿一次好感
- 好感 ≥ `bond_favor`（默认 45）→ 出现「跟我一起走。」→ 结盟
- **话题是一次性的**：聊过就消失，不会重复

### 好感预算

如果你的英雄有 5 个话题，每个最好 +8 / +8 / +10 / +9 / +14 = **49**
门槛 45 → 玩家要**大部分选对**才能结盟。

## 六、状态行（动作 / 姿态）

对话框上方有一行状态，会自动切换：

| 时机 | 显示 |
|------|------|
| 平常 | 按**好感分档**的姿态（`MOODS`）|
| 点开话题时 | 该话题的 `action` |

`MOODS` 目前是全局共用的四档：

```gdscript
{"min": 0,  "text": "他背对着你，手一直没有离开刀柄。"},
{"min": 16, "text": "他侧过身，能看见你在做什么了。"},
{"min": 31, "text": "他把刀放到了一边，虽然还在手边。"},
{"min": 45, "text": "他站到了你半步之后。"},
```

**如果要每个英雄有自己的一套**，告诉我，我把它改成按英雄配置。

## 七、写作要求（重要）

这个游戏的文案规则：

1. **只写现象，不写解释**。不写「他很难过」，写「他说完自己笑了一下」。
2. **三行结构**：场景 → 细节 → 失序。
3. **教皇永不解释**。NPC 也不解释自己。
4. **不出现「卡牌 / 牌组 / 抽牌 / 费用 / 能量」**。
5. 短句。句号。不要感叹号。
6. 留白比说满好。**写到七分停手**。

### 好例子

```
「山没了。」
「石头还在。」
「他站在原地，不知道往哪儿推。」
```

### 坏例子

```
「众神们纷纷陷入疯狂，整个世界都陷入了无尽的混乱与绝望之中！」
```

（形容词堆砌 + 解释 + 感叹号，三条全犯。）

## 八、加一个新英雄要做的

1. 在 `scripts/npc_db.gd` 的 `NPCS` 里加一段（照抄阿喀琉斯的格式）
2. 填 `title` / `greeting` / `topics`
3. 跑一遍游戏，从**存档页 → 调试：英雄 NPC** 看效果
4. 不用改任何其它文件
