# 逐神 · 美术风格规范

> 参考图：夜色 / 羊皮纸 / 金线 / 一个披斗篷的背影。
> 关键词：**水墨感 · 二次元人物 · 双色世界 · 金线边框 · 留白**

---

## 一、核心原则

### 1. 双色世界
整个画面只有两组颜色：**深夜的蓝黑** 和 **羊皮纸的暖白**。
没有中间调，没有鲜艳色。**血** 是唯一允许的第三个颜色，而且只能是小面积。

### 2. 水墨 + 二次元
- **建筑、山水、云** —— 水墨（枯笔、飞白、晕染）
- **人物** —— 二次元（干净的线条、明确的眼睛、头发有块面）

这两者不冲突：参考图里的斗篷就是「水墨的笔触 + 二次元的形体」。

### 3. 金线不画满
边框是**一根极细的金线** + **四角的藤蔓**。
不是粗金框，不是浮雕，不是描边发光。
**细到远看几乎看不见，近看才在。**

### 4. 大面积留白
参考图右侧 60% 是空的。**空的地方比画的地方重要。**

## 三、边框规范

```
┌──────────────────────────────────┐   ← 1px 金线 #C9A86A，40% 透明
│                                  │
│        （内容）                   │   ← 内侧留白：短边 6%，长边 4%
│                                  │
└──────────────────────────────────┘
   ↑
   四角有藤蔓：两根细弧线，从角向内 30~60px
```

| 元素 | 规格 |
|------|------|
| 线宽 | **1~2px**（2048 宽图上 2px）|
| 颜色 | `#C9A86A`，透明度 40%~70% |
| 双线 | 内线 1px，外线 1px，间距 6~10px（大图才用）|
| 角花 | 藤蔓 / 叶脉，弧线，**只有四角**，不连成整圈花纹 |
| 内边距 | 画布短边 × 6% |

**不要**：粗金边、浮雕阴影、发光、欧式卷草满框、二维码式直角。

## 四、人物（英雄立绘）

### 通用要求
- **半身或七分身**，不要全身站桩
- **侧 3/4 脸**，眼睛有高光
- **斗篷 / 披风**占画面 1/3 以上（水墨笔触）
- 背景**纯色**（深蓝黑）或**极淡的羊皮纸**
- **不画武器细节**（刀剑只画轮廓 / 剪影）
- 画面下方 1/5 留白（给名字和台词）

## 七、不要做的事

| ❌ 不要 | 为什么 |
|--------|--------|
| 描边发光 | 廉价 |
| 粗金框 / 浮雕 | 页游感 |
| 满屏花纹 | 脏 |
| 高饱和色 | 破坏双色 |
| 圆形头像框 | 手游感 |
| 多层阴影 | 脏 |
| 斜体 / 艺术字 | 廉价 |
| 战斗特效常驻 | 干扰阅读 |
