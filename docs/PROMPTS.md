# 出图提示词（直接复制）

> 全部按主菜单那张图的风格写：**水墨笔触 + 二次元人物 + 深夜蓝黑 / 羊皮纸双色 + 细金线**。
> 每次出图 = **通用前缀** + **主体描述** + **负面提示词**。

---

> ⚠️ 出图时直接出 **3:4**。如果带水印，导入脚本会切底部 8.5%。

## 通用前缀（每次都带）

```
二次元插画，冷色调，双色配色：深夜蓝黑 #1D3143 与羊皮纸暖白 #F9ECD8，
水墨笔触的衣褶与背景，干净的二次元线稿上色，眼神有高光，
柔和的羊皮纸色轮廓光，大面积留白，淡雅，克制，无鲜艳色，
高质量，精细，8k，
```

## 负面提示词（每次都带）

```
低质量，模糊，多余手指，畸形的手，对称脸，鲜艳色，彩虹色，霓虹，赛博朋克，
3D渲染，写实照片，厚涂油彩，粗金框，浮雕，发光描边，文字，水印，logo，
复杂背景，装饰花纹，卡通Q版，大头娃娃
```

## 七、出图工作流

```
1. 复制「通用前缀」
2. 粘贴某个主体描述
3. 追加「负面提示词」
4. 出图 → 用 tools/import_art.py 转成游戏用的尺寸
```

示例命令：

```bash
python tools/import_art.py 下载/阿喀琉斯.png --kind hero --name 阿喀琉斯
python tools/import_art.py 下载/serpent.png --kind enemy --name serpent
python tools/import_art.py 下载/bg1.png --kind battle --name bg_battle_6
```

## 八、几条经验

| 问题 | 解法 |
|------|------|
| 出图太亮 / 太艳 | 前缀里加强「双色配色」，负面加「高饱和」|
| 人物比例不对 | 主体里写「半身，从胸到膝盖」或「七分身」|
| 背景太满 | 加「大面积留白，背景只有一层色」|
| 手画坏了 | 直接让手「藏在斗篷里」「背在身后」|
| 脸太二次元 / 太幼 | 加「成年，写实比例的脸，眼神有故事」|
| 金框总被画进去 | 负面加「边框，相框，装饰框」|
