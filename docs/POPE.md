# 教皇 · 完整资料

> **一个人活了 380 年。**
> 他不是长生不老，是**用别人的命换自己的时间**。
> 这份文件给他六个阶段、七个决定、五组关系。

---

## 一、他是谁

| 项 | 内容 |
|---|---|
| **俗名** | **艾德蒙·维斯**（Edmund Weiss） |
| **出身** | 赫兰 · 崩解期的一个抄写员之子。生于 373 年（无名之年后的第一年） |
| **教名** | **格里高利九世** |
| **人们怎么叫他** | 不叫名字，叫「**座**」。「座怎么说」= 教皇怎么说 |
| **他怎么称呼自己** | **从来不用「我」**，只说「**这里**」 |
| **接管白塔时** | 47 岁（420 年） |
| **现在的年龄** | 名义上 **427 岁**；实际身体状态约 **50 岁**（530 年之后就没再变过） |
| **他真正怕的东西** | **安静** —— 所以他让唱诗班一直唱 |

---

## 二、六个阶段（每个阶段一个名字，一种人格）

> **教会记录里，这六个人是不同的「座」。**
> 只有他自己知道，是同一个。

### ① 抄写员 · 373~400（27 岁前）

| 项 | 内容 |
|---|---|
| **身份** | 赫兰崩解期的一个抄写员。给快散架的王朝抄最后的公文 |
| **他看见了什么** | 415 年那道「没有任何人签署」的最后命令 —— **是他抄的，也是他放进档案的** |
| **他学到的东西** | **权力不在谁签，在谁保存** |
| **一句话** | 「一道没人签的命令，只要有人把它收好，它就会变成真的。」 |

### ② 修士 · 400~420（27~47 岁）

| 项 | 内容 |
|---|---|
| **身份** | 加入教会（那时教会还只是各国境内的一批人） |
| **他做了什么** | 用十年抄完了崩解期所有还能找到的记录 |
| **他的发现** | **「历史是可以重写的，只要你能毁掉原本。」** |
| **关键事件** | 415 年那份空白命令，他**烧掉了原本**，只留下自己抄的那份 |
| **一句话** | 「我烧的不是纸。我烧的是一个没有人签字的世界。」 |

### ③ 座 · 420~460（47~87 岁）

| 项 | 内容 |
|---|---|
| **怎么上位的** | 420 年冬天，他一个人走进白塔，**没有人拦他** |
| **他做的第一件事** | 把白塔改名圣殿，把塔顶的碎镜子熔成一只**眼睛** |
| **他做的第二件事** | 「神谕录入」：宣布所有神都已沉默，**从此只有教皇能听见** |
| **他的手段** | **不靠武力，靠「记录」** —— 他掌握了所有的档案 |
| **一句话** | 「我不需要你们信我。我需要你们**只能听我**。」 |

### ④ 立法者 · 460~530（87~157 岁）

| 项 | 内容 |
|---|---|
| **这是他最长的一个阶段** | 70 年 |
| **他建立的东西** | 圣骸行者 / 灰烬修女 / 唱诗班 / 执灯者 / 「清点」制度 |
| **他真正的杰作** | **「无名者一律视为已死」**（498 年）—— 一句话让一整个阶层消失了 |
| **他为什么开始怕死** | 他 130 岁那年，第一次看见自己的手在抖 |
| **一句话** | 「活人不重要。**名单才重要。**」 |

### ⑤ 不腐者 · 530~700（157~327 岁）

| 项 | 内容 |
|---|---|
| **转折点** | 530 年，他把自己接到伪世界树上 |
| **他用了什么** | **「挂在树上的人」** —— 那批没死也没活的 |
| **代价** | 他的身体停止衰老，也**停止生长**。脸像蜡 |
| **他失去了什么** | **他不再记得自己的母亲长什么样**（这是他的原话，只说过一次） |
| **一句话** | 「我记得所有事。**除了她的脸。**」 |

### ⑥ 座 · 700~800（327~427 岁）

| 项 | 内容 |
|---|---|
| **状态** | 不出面。**632 年起，他连续三年没露面，教会宣布他在「听」** |
| **他的权威怎么维持** | 靠**沉默**。他不说话，别人就不敢替他说话 |
| **他最后悔的事** | **他把「听见」当成了权力** —— 而真正的神，从来没听见过他 |
| **一句话** | 「我听了四百年。**没有一次回答。**」 |

## 三、七个关键决定

| 年 | 年龄 | 决定 | 后果 | 他后来怎么看 |
|---|---|---|---|---|
| **415** | 42 | **烧掉那份空白命令的原本** | 王朝的终点被改写成「教会接管」 | 「我烧的是一个没有人签字的世界。」 |
| **420** | 47 | **一个人走进白塔** | 教会成了唯一的国 | 「我没有走进白塔。白塔在等我。」 |
| **424** | 51 | **神谕录入** | 只有他能「听见」 | 「那不是谎言。**我真的听见了。**」 |
| **436** | 63 | **圣骸行者建制** | 把树上的人做成守卫 | 「他们本来就不算活着。我只是让他们有用。」 |
| **498** | 125 | **无名者一律视为已死** | 一整个阶层被抹去 | 「没有了名字，就不需要负担。」 |
| **512** | 139 | **接伪世界树的根** | 开始不死 | 「我以为我在赢。」 |
| **530** | 157 | **接自己上去** | 停止衰老，也停止生长 | 「我记得所有事。除了她的脸。」 |

## 四、他和其他势力的关系

### 与他自己的教会

| 关系 | 内容 |
|---|---|
| **他不需要信徒** | 他只需要**记录**。信徒可以不信，但不能不在名单上 |
| **他不信任任何人** | 审判庭 718 年开始审自己人 —— **是他下的令** |
| **他对唱诗班的态度** | 唱诗班是他唯一允许「发出声音」的机构。**因为他怕安静** |
| **他知道教会里有人在等他死** | 他知道是谁。名字他记得一清二楚 |

### 与「挂在树上的人」

| 关系 | 内容 |
|---|---|
| **他们是什么** | 落地那夜没掉下来的那批人。没死也没活 |
| **他怎么用他们** | 圣骸行者的躯体 / 他自己的续命 / 伪世界树的接口 |
| **他对他们的看法** | 「**他们不算人。**」（但他从不在公开场合说这句） |
| **他真正怕的** | **有一天他们开口说话** |

### 与游灵（玩家）

| 关系 | 内容 |
|---|---|
| **他知道游灵存在** | 795 年起，陆续有游灵出现。**前面几批都失败了** |
| **他怎么处理** | **不阻止。** 他甚至希望游灵能走到他面前 |
| **为什么** | 因为他想看看**一个没有执念的东西**，会怎么面对一个什么都放不下的人 |
| **他的期待** | 「**你替我放下吧。**」—— 这句话可以是最终战的台词 |

### 与五国

| 国 | 关系 |
|---|---|
| **赫兰** | **他的母国**。他把它变成了圣殿。他对赫兰没有感情，只有记录 |
| **北马克** | 太难管。**他不管** —— 只要北马克每年报上人数 |
| **卡斯提** | **他最尊重的地方** —— 因为卡斯提人从不跟他谈信仰，只谈价钱 |
| **三渠** | **他最不耐烦的地方** —— 318 年他本想介入，后来发现不值得 |
| **无声之地** | **他的「仓库」** —— 献祭季从这里拿人，因为「这里的人不算人」 |

### 与众神

| 关系 | 内容 |
|---|---|
| **他不信神** | 他信的是「**记录**」，不是神 |
| **但他必须让神「沉默」** | 因为活着的神会跟他抢「听见」的资格 |
| **他知道真相** | **神是真的疯了，而且还在疯。** 他一直在听，一直没等到回答 |
| **他的最后一句** | 「我听了四百年。没有一次回答。」 |

## 五、可以用的具体细节

| 细节 | 用法 |
|---|---|
| **他从不说「我」** | 所有台词里，他自称「这里」「这座」「这个位置」 |
| **他的脸像蜡** | 775 年之后再没人见过他的脸 |
| **他怕安静** | 无声之年（752）是他最恐惧的一年 |
| **他记得所有事，除了母亲的脸** | 唯一一次露出「人」的地方 |
| **他记得每一个等他死的人的名字** | 但他一个也没动 |
| **他把铁冠熔进了眼睛** | 288 年那顶铁冠，现在是他「眼睛」的一部分 |
| **他一直在听** | 632 年后，他的「听」成了教会最有力的政治语言 |

## 七、一句总结

> **他不是想当神的疯子。他是一个保存了所有记录、然后被记录困住的人。**
>
> 他从来没有听见神。他只是**把所有「听见神的人」都处理掉了**，
> 于是只剩下他一个人还在听。
