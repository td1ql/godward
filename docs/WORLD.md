# 《逐神》世界观设定

> 本文档是《逐神》的世界观与核心系统设计基准。所有文本、命名、系统设计以此为准。

---

## 一句话

> 每隔数十年，诸神开启「逐神之戏」。来自各地的冒险者被投入神域，互相厮杀、穿越试炼。最终的胜者，将获得登临神堂的资格——这是教皇告诉所有人的话。

---

## 世界真相

| 层 | 表面 | 真相 |
|----|------|------|
| 1 | 神明赐福，胜者登神 | 神明**没有神智**，只是纯粹的力量 |
| 2 | 逐神是神圣的选拔 | 是**教皇的谎言**，用来筛选心智强弱的棋子 |
| 3 | 胜者登神 | 胜者只是获得**接见教皇的资格**；心智弱者沦为**傀儡** |

---

## 玩家

- 身份：一名参赛的冒险者
- **本体**：创世神的一点思绪
- 肉身被教皇做成傀儡后，思绪会复苏，附到新的身体上，参加下一次逐神游戏
- 这就是「转生」

---

## 逐神游戏

- 每局固定 **6 名参赛者**（玩家 + 5 名 NPC）
- 每局重新抽取 NPC，**不重复**
- 参赛者会互相残杀，中途不断有人被淘汰
- 玩家可在神域中遇见其他参赛者，选择**交谈**或**躲避**
- 少数参赛者可结为同盟

---

## 转生

- **只有见到教皇才算一次转生**；中途死亡只是重开本局
- 每次转生，玩家附身的身体不同，随机获得 **2~3 个词条**
- 词条可能是增益，也可能是减益，体现「附身的随机感」
- 转生次数持久保存

### 词条示例

| 词条 | 效果 |
|------|------|
| 强健 | 最大生命 +15 |
| 富裕 | 初始金币 +30 |
| 敏锐 | 初始手牌 +1 |
| 残躯 | 最大生命 -10 |
| 健忘 | 初始手牌 -1 |
| 神眷 | 开局获得一张额外卡牌 |

---

## 参赛者与同盟

- 每名 NPC 有**特性**（好战 / 狡诈 / 虔诚 / 疯狂…）
- 遇见时可选择**交谈**或**躲避**，结果因 NPC 而异
- 好感达到阈值可**结盟**
- 同盟助力分两种：
  - **少数 NPC**：作为友军单位，一起参加最终战
  - **多数 NPC**：以卡牌、增益的形式提供助力

---

## 守门人与教皇

- **守门人**：神堂之门前的最后试炼
- **教皇**：
  - 10 次转生之前，见到教皇 = 本局结束（被留下 / 被做成傀儡）→ 转生 +1
  - 10 次转生之后，意志足够强大，**可以真正与教皇战斗**

---

## 结局结构

```
第 N 次转生（N < 10）
   → 穿越神域 → 守门人 → 见到教皇 → 转生 N+1

第 10 次转生之后
   → 穿越神域 → 守门人 → 与教皇决战 → 真结局
```

---

## 卡牌的世界观解释

| 类型 | 解释 |
|------|------|
| 行动牌 | 武技与装备 |
| 效果牌 | **献祭**：消耗其他牌换取力量 |
| 遭遇牌 | 神域中的意外：神谕、灾厄、陷阱 |

---

## 设计决定记录

1. 只有见到教皇才转生；中途死亡 = 重开本局
2. 每次转生随机 2~3 个词条（含减益）
3. 同盟 NPC：少数作为友军单位参战，多数以卡牌/增益助力
4. NPC 会互相残杀，随进程被淘汰
5. 10 次转生是门槛，之后才能与教皇战斗
