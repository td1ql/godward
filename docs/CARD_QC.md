# 卡面质检标准（Card Art QC）

> 目标：**合格率 ≥ 50%**（用户明确要求）。不合格的一律打回重画，不允许「差不多能用」。

## 一、四道关口（任一不过 = 打回）

### Gate 1 · 脸
- ❌ 五官融化 / 歪斜 / 不对称到明显
- ❌ 无脸（该有脸却是一团黑或一块空白）
- ❌ 多眼 / 少眼 / 眼睛位置错乱
- ❌ 恐怖谷（眼距过窄、眼白过多、牙齿畸形）
- ❌ 脸被裁掉一半或背对镜头该露不露

### Gate 2 · 好看
参考高赞奇幻插画的共性，逐项打分（每项 0/1）：
- 强剪影：缩成黑影也能认出在做什么
- 明确光源：光从哪来一眼可辨
- 明度层次：至少三个层次（暗底 / 中调 / 亮部）
- 克制高光：只有一处主高光，不遍地反光
- 视觉焦点：第一眼落在脸或手上，不是背景杂物
- **得分 < 4/6 = 打回**

### Gate 3 · AI 感
以下任一项明显 = 打回：
- 背景细节崩解（远处物件糊成一团 / 结构不成立）
- 光源矛盾（两个方向的光打架）
- 无意义装饰（漂浮碎片、看不懂的符号、重复花纹）
- 塑料质感 / 过度光滑（水墨风格下看「墨色是否像真的墨」）
- 过度锐化或完全没有颗粒（边缘像刀切）
- 手崩：多指 / 融合 / 断肢 / 手指数量不对
- 对称过度（机械对称，不像手画）

### Gate 4 · 构图与内容
- ❌ 裁切到只剩局部（只有手 / 只有衣角 / 只有背景）
- ❌ 人物出框或过小
- ❌ 动作与卡名无关
- ❌ 出现中世纪之外的元素（枪械 / 机械 / 现代建筑 / 日式和服）

## 二、判定记录格式

每张卡记一行，存进 `docs/CARD_QC_LOG.md`：

```
| 卡名 | 版本 | Gate1 | Gate2 | Gate3 | Gate4 | 结论 | 打回原因/改法 |
|------|------|-------|-------|-------|-------|------|----------------|
| 打击 | v7-1 | ✅ | 5/6 | ✅ | ✅ | 通过 | — |
| 淬毒 | v7-1 | ✅ | 3/6 | 光源矛盾 | ✅ | 打回 | 改描述加强侧光 |
```

## 三、打回后的处理

1. **第一次打回**：同描述重抽（换 seed），抽 3 版取最好
2. **第二次打回**：改描述（加姿态 / 换场景 / 换服装）
3. **第三次打回**：改描述 + 改构图（换景别、换朝向）
4. **五次都不行**：标为「不可达」，写进最终报告的失败清单

## 四、合格率统计

```
合格率 = 通过张数 / 214
```

**每轮结束时更新一次**，并记录当轮通过/打回数量与主要原因。
