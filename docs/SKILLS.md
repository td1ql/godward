# 职业技能总表

16 个职业，每个一个专属技能。**战斗中满足条件才能用，每场一次。**

## 加新技能 / 改技能

改 `scripts/skill_db.gd` 的 `SKILLS` 字典：

```gdscript
"职业名": {
	"name": "技能名",           // 中文，2~3 字
	"en": "EN NAME",            // 英文，全大写
	"cond": "no_attack_3",      // 触发条件，见下表
	"hint": "连续三回合不曾出手", // 条件提示（给玩家看）
	"line": "她把手放在胸口，站住了。", // 演出时的台词
	"effect": {"block": 28},   // 效果
	"fx": "guard",              // 演出类型
},
```

### 可用的触发条件

| kind | 意思 |
|------|------|
| `no_attack_3` | 连续 3 回合没有打出过攻击牌 |
| `turn_min_5` | 第 5 回合之后 |
| `hp_below_30` | 生命低于 30% |
| `block_zero` | 格挡被打到 0（第 2 回合起） |
| `hand_min_6` | 手牌 6 张以上 |
| `damage_taken` | 本场累计受过 20 点以上伤害 |
| `energy_zero` | 能量用完（第 2 回合起） |
| `enemy_poison` | 敌人中毒 5 层以上 |

### 可用的效果字段

| 字段 | 意思 |
|------|------|
| `block` | 加格挡 |
| `heal` | 回血 |
| `energy` | 加能量 |
| `draw` | 抽牌 |
| `damage_all` | 对敌人造成伤害 |
| `damage_per_poison` | 每层中毒造成伤害 |
| `damage_per_card` | 每张手牌造成伤害 |
| `damage_self_hp_pct` | 按已损失生命比例造成伤害 |
| `burn_hand` | 烧掉全部手牌 |
| `mult_next` | 本回合攻击倍率 |
| `status_all` | 给敌人上状态 |
| `status_self` | 给自己上状态 |
