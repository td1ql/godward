# 美术资源清单

> 只换图，不用改代码。按这张表把图放进对应路径、命名一致，游戏自动生效。
> 所有图统一 **WebP**，不要 PNG / JPG。

---

> ⚠️ 全部立绘统一 **3:4（670×893）**。不要用 2:3，会切掉头顶。
> AI 出图常在右下角带水印，导入脚本会自动切掉底部 8.5%。

## 三、战斗背景（14 张）

**路径**：`assets/art/bg/bg_battle_*.webp`

| 项 | 要求 |
|----|------|
| 尺寸 | **2048 × 1089**（16:9 略宽，游戏会裁）|
| 构图 | **下 1/3 是地面**（角色站的地方），**上 2/3 是天空/墙** |
| 中景 | **留空**（敌人立绘会叠在右侧 x≈1100~1250）|
| 不要 | 不要画人物，不要画 UI |

| 文件 | 用在哪 |
|------|--------|
| `bg_battle_1` ~ `bg_battle_5` | 第一幕 · 人间（荒原、断墙、远山）|
| `bg_battle_2_1` ~ `2_3` | 第二幕 · 神国（苍白、空旷、巨大的门）|
| `bg_battle_3_1` ~ `3_3` | 第三幕 · 神土（血红的天、倒下的神像）|
| `bg_battle_3_boss` | 耶梦加得 |
| `bg_battle_odin` / `hermes` / `hephaestus` / `asclepius` / `tut` | 特定神 |

**画法**：远景水墨（枯笔飞白、大面积留白），近景地面用一根墨线勾。**不要**画地面纹理细节。

## 九、导入流程

### 手动
1. 图放进对应路径
2. 文件名和表里一字不差
3. 回 Godot 里它会自动导入（`.import` 文件会自动生成）

### 用脚本批量处理（推荐）

```bash
python tools/import_art.py 源图.png --kind vocation --name 阿喀琉斯
```

脚本会：
- 裁成对应比例
- 缩放到标准尺寸
- 转成 WebP（质量 88）
- 放进正确路径
