# 十六个职业 · 故事素材卡

> 每个职业：**姓名 / 来自哪国 / 哪一年 / 那年的历史背景 / 死前那一刻的念头 / 对话关键词**
>
> 这是**素材**，不是成品。你从这些卡片里取，写你自己的版本。
>
> 原则：**游灵只附身死人**。每一张卡写的都是「一个人怎么死的」，以及**他死前没放下什么**。

## 01 · 等待丈夫的新娘

| 项 | 内容 |
|---|---|
| **姓名** | **玛蒂尔达**（别人叫她「玛蒂」） |
| **来自** | **卡斯提**（码头区） |
| **那年** | **134 年**，白银战争的第二年 |
| **历史背景** | 白银战争打到第二年，卡斯提的商船**全部被两边征用**。港口的女人每天都在码头等船回来 |
| **她是什么人** | 码头工人的妻子。她丈夫的船叫「三桅」，船长是巴尔托 |
| **关键的物件** | 她每天在门口摆**两个碗**。三年，一天没断 |
| **她死前在做什么** | 有人报信说北边来了一队船。她跑到码头，**跑的时候打翻了一个碗** |
| **死法** | 她跑到码头，看见不是那艘船，就站住了。**站了一夜**。第二天早上人还在那儿 |
| **死前那一刻的念头** | **「船会回来的。」** |
| **对话关键词** | **等 / 两个碗 / 门没锁 / 跑的时候打翻了碗** |
| **可用台词** | 「我不是在等他。**我是在等那个碗被用上。**」 |
| **与游灵的关系** | 她死的时候手上还握着门闩。**游灵附上去，第一感觉是手心的木头** |

## 02 · 失明的守钟人

| 项 | 内容 |
|---|---|
| **姓名** | **小约尔格**（教名叫约尔格，所有人都叫他小约尔格，因为他一直没长大） |
| **来自** | **赫兰**（首都，大钟楼） |
| **那年** | **342 年**（钟楼倒塌） |
| **历史背景** | 塌之前三个月，钟楼的地基一直在渗水。**没人管**，因为「钟楼是王朝的，不是我们的」 |
| **他是什么人** | 钟楼的敲钟学徒，12 岁进宫，敲了三十年。**后来瞎了**，靠摸钟的震动报时 |
| **关键的物件** | 一根**绳子**。他拉着绳子听震动判断时辰 |
| **他死前在做什么** | 342 年那天，他照常去敲钟。**他摸到了墙在动**，但他以为是自己在抖 |
| **死法** | 钟楼塌了。他**没有被压死**，是被埋在里面，活了三天 |
| **死前那一刻的念头** | **「钟还在响吗？」** |
| **对话关键词** | **摸 / 震动 / 时辰 / 「我以为是我在抖」** |
| **可用台词** | 「我敲了三十年。**从来没有人告诉我，我敲的是几点。**」 |
| **与游灵的关系** | 他死了以后还在「敲」——**游灵附上去，会一直听见钟声** |

## 附录一：16 个「死前那一刻的念头」汇总

> 这些就是**游灵附身时附到的东西**。

| # | 念头 |
|---|---|
| 1 | 「船会回来的。」 |
| 2 | 「钟还在响吗？」 |
| 3 | 「再走一天。」 |
| 4 | 「我什么都没说。」 |
| 5 | 「我说过的。」 |
| 6 | 「还差一笔。」 |
| 7 | 「旗还在。」 |
| 8 | 「我叫什么来着。」 |
| 9 | 「水不冷。」 |
| 10 | 「烧完了就没人记得了。」 |
| 11 | 「他们会来的。」 |

## 附录三：写作时的三条纪律

1. **不要写「大事件」** —— 写「那个人那天在做什么」
2. **不要解释历史** —— 历史从物件里透出来（一个碗、一块门板、一副号角）
3. **结尾必须是一句短句** —— 不能超过 10 个字，最好是一个动作
