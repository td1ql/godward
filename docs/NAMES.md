## 一、四个朝代 · 历代国王

> 命名风格：两字名 + 一个绰号（绰号是后人加的，往往比名字更流传）
> 420 年 = 三个王朝 + 两段「没有王的时期」

### ① 赫兰 · 灰隼王朝（0~147）「立塔的一族」

| 代 | 名 | 绰号 | 在位 | 一句话 |
|---|---|---|---|---|
| 1 | **赫拉尔** | 杀神者 | 0~31 | 灰隼原野杀神使，抢回三百人 |
| 2 | **索恩** | 立塔者 | 31~62 | 下令修白塔，一辈子没看见它完工 |
| 3 | **海妲** | 女墙 | 62~89 | 唯一的女王，修完了长城 |
| 4 | **埃德蒙** | 驿路王 | 89~118 | 设驿站，让消息第一次跑得比马快 |
| 5 | **奥托** | 立法者 | 118~147 | 写了《灰隼律》。**他死后无嗣，灰隼一脉断绝** |

### ② 银冠王朝（147~262）「白银换来的一族」

> 白银战争的将军起兵夺位。国徽从灰隼换成银冠。

| 代 | 名 | 绰号 | 在位 | 一句话 |
|---|---|---|---|---|
| 1 | **康拉德** | 银币 | 147~171 | 打赢白银战争上位，国库是空的 |
| 2 | **赫尔加** | 药后 | 171~180 | 大瘟疫时进疫区，死于疫病 |
| 3 | **巴尔杜** | 无嗣 | 180~182 | 死时没有儿子 |
| 4 | **雷纳德** | 北座 | 182~201 | 三王并立的胜者，杀了两个侄子 |
| 5 | **伊莎** | 摄政 | 201~214 | 雷纳德的妹妹，替年幼的侄子摄政 |
| 6 | **菲力** | 空位 | 214~231 | 被篡位，史书只写「病重」 |
| 7 | **戈德** | 无记 | 231~244 | 第二次篡位上台，继位记录空白 |
| 8 | **阿尔** | 王座之末 | 244~262 | 王座会议成立，王权被架空。**银冠一脉自此无权** |

### ③ 铁冠王朝（262~288）「只戴了二十六年的冠」

> 王座会议的贵族们推出来一个「能打的人」。他从头到尾没被承认过。

| 代 | 名 | 绰号 | 在位 | 一句话 |
|---|---|---|---|---|
| 1 | **乌尔里希** | 铁冠 | 262~281 | 贵族推举的将军。终身未加冕，自己打了顶铁冠戴上 |
| 2 | **乌尔里希二世** | 短命 | 281~288 | 他儿子。**白塔失火那年死在里面**，铁冠熔化，尸骨没找到 |

> 288 年白塔失火，铁冠王朝一夜终结。
> **「那顶冠是铁做的 —— 铁会烧，金不会。」**（后世教会的话）

### ④ 王座会议期（288~372）「没有王的八十四年」

> 没有王朝。由贵族集体议政，每年推举一个「坐席者」。
> 史书上这一段几乎没有名字。

| 年 | 坐席者 | 一句话 |
|---|---|---|
| 288~301 | **老赫尔曼** | 第一个坐席者，立了「不得称王」的规矩 |
| 301~318 | **（无记）** | 三渠之乱，换了七个坐席者 |
| 318~334 | **贝尔纳** | 镇压三渠之乱的那个，据说是教皇的远亲 |
| 334~351 | **（无记）** | 伪经之祸，焚书三日 |
| 351~372 | **最后一个坐席者** | 名字没留下来。372 年无名之年，户籍崩塌 |

### ⑤ 崩解期（372~420）「没有人的四十八年」

> 没有王，没有坐席者，没有名字。
> 这一段只有年号，没有人物。

| 年 | 事件 |
|---|---|
| 372 | **无名之年**。没有记录 |
| 381 | **哑者起义**。没有记录 |
| 392 | **最后一支勤王军**。没有记录 |
| 405 | **星历废止**。没有记录 |
| 415 | **王朝最后一道命令**。**没有任何人签署** |

**几个可以用的细节：**
- **第 14 代之后就没有「第十四代」这个说法了** —— 因为王朝反复断绝，没人算得清
- **赫尔加（药后）** 死后，人们把她用过的药方抄在布上带在身上 —— **这是「药渣」的来历**
- **乌尔里希的铁冠** 后来被教会熔了，据说「掺进了白塔那只眼睛」
- **王座会议期**的「坐席者」**不叫王** —— 所以这一百多年里，没有一个人有资格说「我是王」

## 二、五个国家（不是一个王国，是一个世界）

> 落地的那个夜晚，人不是落在一处。
> 落在不同地方的人，后来长成了五个不一样的国家。

### 命名逻辑：**每个国家的名字，出自不同的人**

> 这一点比名字本身重要 —— **谁给这里起的名字，谁就是这里真正的主人。**

| # | 国名 | 谁起的 | 词源 | 后来的命运 |
|---|---|---|---|---|
| **1** | **赫兰** | **自己起的** | 取自开国者**赫拉尔**的名字。「赫兰」= 赫拉尔之地 | **420 年变成伪神国** |
| **2** | **北马克** | **旧帝国的行政官** | 「马克」是边境领的意思。**帝国早亡了，这个称呼还在** | 304 年后各自为政，**二十二个领，谁也不服谁** |
| **3** | **卡斯提** | **商人自己起的** | 古语「**卡斯**」= 账。**卡斯提 = 有账的地方** | 白银战争的赢家，最后的输家 |
| **4** | **三渠** | **三座城各出一个字** | 铁桥、盐井、断渠 —— 三渠共用一条河，河就是「渠」 | 318 年同时造反，被镇压 |
| **5** | **无声之地** | **教会起的** | 教会不承认这里有人，所以不承认这里有地名 | 献祭季从这里拿人 |

### 五个国家的关系（可以当冲突源）

| 关系 | 内容 |
|---|---|
| **灰隼 ↔ 卡斯提** | 130 年白银战争。打了六年，灰隼赢了，但国库空了 |
| **灰隼 ↔ 北马克** | 名义上臣属，实际上 40 年修完长城后就没再听调 |
| **灰隼 ↔ 三渠** | 318 年三渠同时造反。原因是**断渠**在上游修了水坝 |
| **三渠 ↔ 卡斯提** | 盐井的盐只能从卡斯提出海。卡斯提抽三成 |
| **北马克 ↔ 无声之地** | 长城之外就是无声之地。**守长城的人知道那边有什么，所以从不越界** |
| **全体 ↔ 教会** | 420 年之前，教会只是各国境内的一批人；420 年之后，教会成了唯一的国 |

## 三、五个国家的风俗与说话方式

> 写对话时最需要的一节：**同样一句意思，五个国家的人说法不一样。**

### ① 赫兰（中部平原 · 王权）

| 项 | 内容 |
|---|---|
| **怎么看自己** | 「我们是把人从神手里抢回来的那一批」 |
| **说话方式** | **完整句、爱用「我们」、有礼貌但端着**。对上位者用「您」，对下位者不用 |
| **口头禅** | 「按律」「合规矩」「这事得报上去」 |
| **禁忌** | **不提「杀神使」的细节**。只说是「奇迹」 |
| **葬俗** | 土葬，坟头不立碑，只在坟前放一块**没有字的石头** |
| **打招呼** | 「愿你没有事要报上去。」（**反话**，意思是「愿你今天平安无事」） |
| **例子** | 「按律，第七哨塔的补给该在秋分前到。**这事得报上去。**」 |

### ② 北马克（北方 · 领主联盟）

| 项 | 内容 |
|---|---|
| **怎么看自己** | 「我们守着墙。**墙那边是什么，我们不说**」 |
| **说话方式** | **短句、句子间有停顿、很少用敬语**。喜欢用**反问**代替回答 |
| **口头禅** | 「嗯。」「随你。」「雪要来了。」 |
| **禁忌** | **不谈论长城之外**。也**不问别人的名字** |
| **葬俗** | 不葬。**把人放在雪里，等雪化** |
| **打招呼** | 「还活着？」（**这就是问好**） |
| **例子** | 「你从南边来？嗯。**雪要来了。**」 |

### ③ 卡斯提（南方海岸 · 商人共和）

| 项 | 内容 |
|---|---|
| **怎么看自己** | 「我们不问你是谁，只问你付不付」 |
| **说话方式** | **语速快、爱用数字、习惯性加一句「不过」**。称呼任何人都是「先生 / 女士」，不管身份 |
| **口头禅** | 「这得算一算」「不过——」「按市价」 |
| **禁忌** | **不谈信仰**。在卡斯提提「神」是失礼的 |
| **葬俗** | 海葬。**骨灰要撒在港口外面**（不然影响航道） |
| **打招呼** | 「今天有风。」（问的是天气，意思是「今天能做买卖吗」） |
| **例子** | 「这得算一算。按市价是三十，不过——你要是现金，二十五。」 |

### ④ 三渠（东南 · 城邦同盟）

| 项 | 内容 |
|---|---|
| **怎么看自己** | 「我们三座城共用一条河。**谁在上游，谁说了算**」 |
| **说话方式** | **爱打比方、爱提河、爱说「上面」「下面」**。三座城的人互相看不顺眼 |
| **口头禅** | 「水往下走。」「上面的人不会管。」「这是铁桥的规矩。」 |
| **禁忌** | **不说「坝」这个字**（318 年之后成了禁忌） |
| **葬俗** | 水葬。**放木筏上顺流而下** |
| **打招呼** | 「水还够吗？」 |
| **例子** | 「水往下走。上面的人不会管下面的人死活 —— 这是铁桥的规矩。」 |

### ⑤ 无声之地（极西 · 无国家）

| 项 | 内容 |
|---|---|
| **怎么看自己** | **没有「自己」这个概念**。这里的人不组成群体 |
| **说话方式** | **说得很短，像费力气**。**不说自己的名字**（说了就会被记住） |
| **口头禅** | 没有。**沉默是常态** |
| **禁忌** | **不回头**。往东走的人不回头看 |
| **葬俗** | 没有。**死了就留在原地** |
| **打招呼** | 不打招呼。**互相看一眼就走开** |
| **例子** | 「……」（**这里的人几乎不说话。开口就已经是大事了**） |

### 五国对比速查

| | 赫兰 | 北马克 | 卡斯提 | 三渠 | 无声之地 |
|---|---|---|---|---|---|
| **句长** | 长 | 短 | 快 | 中 | 极短 |
| **敬语** | 有 | 无 | 一律用 | 分城 | 无 |
| **爱说什么** | 规矩 | 雪 | 钱 | 水 | 不说 |
| **最忌什么** | 提杀神使 | 长城外 | 提神 | 说「坝」 | 说名字 |

| 国 | 样本 |
|---|---|
| **赫兰** | 「按律，我该先问你姓名。**不过我猜你不会说。**」 |

| **卡斯提** | 「三十。不过——你要是现在付，二十五。**这得算一算。**」 |

## 四、教皇

> **他只有一个人。** 从 420 年到 800 年，一直是同一个。

| 项 | 内容 |
|---|---|
| **俗名** | **艾德蒙·维斯**（Edmund Weiss）—— 落地后第七代人的后代 |
| **教名** | **格里高利九世**（借用了历史上最有名的教皇名号之一） |
| **人们怎么叫他** | 不叫名字，叫「**座**」。「座怎么说」= 教皇怎么说 |
| **他自己怎么称呼自己** | 从来不用「我」，只说「**这里**」 |
| **年龄** | 接管白塔时 47 岁，现在名义上 427 岁 |
| **身体** | 脸像蜡。不会老，但也没有再长大（530 年之后） |
| **他真正怕的东西** | **安静** —— 所以他让唱诗班一直唱 |

**参考的多个历史人物（你可以混着用）：**

| 人物 | 借他什么 |
|---|---|
| **格里高利七世** | 教权高于王权的理论，和「皇帝跪在雪地里」那种姿态 |
| **英诺森三世** | 行政天才，把教会变成一个真正的国家机器 |
| **腓特烈二世** | 反过来——一个不信仰自己宗教的宗教领袖 |
| **熙笃会的贝尔纳** | 语言的力量，能用一句话让人去打仗 |
| **某个活得太久的老人** | 记忆衰退但权威不减，说重复的话被当成神谕 |

## 六、教会职衔

| 职衔 | 职责 | 一句话 |
|---|---|---|
| **教皇** | 唯一能「听见」的人 | 他不说话的时候，就是神在说话 |

## 九、命名规则（免得越写越乱）

1. **人名**：欧洲音译（赫拉尔 / 索恩 / 海妲 / 埃德蒙）
2. **绰号**：中文意译（杀神者 / 立塔者 / 女墙）
3. **地名**：中文意译（灰隼原野 / 铁桥 / 盐井）
4. **教会职衔**：中文意译（执灯者 / 灰烬修女）
5. **不出现现代词**：没有「主义」「社会」「科学」「系统」
6. **越古老的东西，名字越短**：神的真名没人知道
