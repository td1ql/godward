# 对话分支写作手册

> 目标：**16 个职业 × 18 个英雄 = 288 种见面对话**，每种都不同。
> 这份文档用**思维导图 + 表格**的形式，让你能直接看着写。

---

## 一、先看结构（三层）

```mermaid
flowchart TD
    A["玩家走近：等待丈夫的新娘"] --> B["t1 初见反应<br/>（每个职业不同）"]
    B --> C{"玩家回答"}
    C -->|"「守望？」"| D1["回应 +1"]
    C -->|"（不说话，一同守望）"| D2["回应 +5"]
    C -->|"「为什么？」"| D3["回应 +3"]
    D1 --> E["t2 深入"]
    D2 --> E
    D3 --> E
    E --> F{"玩家回答"}
    F -->|"「那人是我的丈夫」"| G1["t3-1 他说：寒冬最无情<br/>+20"]
    F -->|"「那人是你的爱人吗」"| G2["t3-2 他说：荣耀是高台<br/>+1"]
    F -->|"「那人是你的亲人吗」"| G3["t3-2<br/>+2"]
    G1 --> H1["玩家：思念是风<br/>「再见」<br/>结束 +5 生命"]
    G2 --> I1["t3-2 的两个回答<br/>+8 / +10"]
    G3 --> I1
```

**三层就够**：初见 → 深入 → 分叉/结束。再长玩家记不住。

## 三、阿喀琉斯 × 等待丈夫的新娘（完整样例）

```mermaid
flowchart TD
    T1["t1 初见<br/>「这位小姐好像也有着一段守望的过往」<br/>「我能看见你眼神中的思念。」"]
    T1 --> R1["「守望？」<br/>+1"]
    T1 --> R2["（不说话，一同守望）<br/>+5"]
    T1 --> R3["「为什么？」<br/>+3"]
    R1 --> T2
    R2 --> T2
    R3 --> T2
    T2["t2 「我的确也曾如此守望，日复一日」<br/>「我们都为一个无法放下的人而背起了一段过去」"]
    T2 --> A1["「那人是我的丈夫」<br/>+5"]
    T2 --> A2["「那人是你的爱人吗」<br/>+1"]
    T2 --> A3["「那人是你的亲人吗」<br/>+2"]
    A1 --> T3A["t3a 寒冬最无情<br/>+20，+5 生命，结束"]
    A2 --> T3B
    A3 --> T3B
    T3B["t3b 「曾经的我将荣耀视作生命」"] --> B1["「向荣耀发问？」<br/>+8"]
    T3B --> B2["「向他的挚友发问？」<br/>+10"]
```

### t1 · 初见

| 项 | 内容 |
|----|------|
| 动作 | 他看了你一眼，又回过头看向远方。 |
| 台词 | 「这位小姐好像也有着一段守望的过往」<br>「我能看见你眼神中的思念。」 |

| 回答 | 他的回应 | 好感 |
|------|----------|------|
| 「守望？」 | 「没错，女士，我于此处守望远方。」<br>「以此来怀念我的挚友。」 | +1 |
| （不说话，尝试与他一同守望） | 他只是轻轻看了你一眼。<br>又望向远方微微叹气 | +5 |
| 「为什么？」 | 「当一个人踌躇于他的过往时」<br>「便会想要守望远方了」<br>「就好像我已经开始向前了」 | +3 |

### t2 · 深入

| 项 | 内容 |
|----|------|
| 动作 | 他长舒了一口气。 |
| 台词 | 「呼~」<br>「我们都为一个无法放下的人而背起了一段过去」<br>「我的守望或许只是片刻休憩。」 |

| 回答 | 他的回应 | 好感 | 走向 |
|------|----------|------|------|
| 「那人是你的爱人吗」 | 「我并无爱人」<br>「他是我的挚友」 | +1 | → t3b |
| 「那人是你的亲人吗」 | 「并不是，尽管我爱着他们」<br>「他是我的挚友」 | +2 | → t3b |
| 「那人是我的丈夫」 | 他没说话。<br>只是静静等候着下文 | +5 | → **t3a** |

### t3a · 丈夫线（结束）

| 项 | 内容 |
|----|------|
| 动作 | 他温和的与你对视。 |
| 台词 | 「女士，寒冬是最无情的季节。」<br>「我为你丈夫的离去而悲伤。」<br>「但四季轮转，就让这痛苦深埋于风雪，在春天，夏天，秋天继续向前吧。」 |

| 回答 | 结果 | 好感 |
|------|------|------|
| 「感谢你的开解，但思念是风，我无法令它停止。」<br>「再见。」 | （你的眼角有泪滴凝聚）<br>**结束对话，+5 生命** | +20 |

### t3b · 荣耀线

| 项 | 内容 |
|----|------|
| 动作 | 他朝来路看了一眼。 |
| 台词 | 「唉——无妨」<br>「曾经的我将荣耀视作生命」<br>「而荣耀是危险的高台」 |

| 回答 | 他的回应 | 好感 |
|------|----------|------|
| 「向荣耀与曾经发问？」 | 「我的荣誉，我的胜利」<br>「我是如此坚决的捍卫它」 | +8 |
| 「向他的挚友发问？」 | 「他为我的愚蠢偏执而死。」<br>他回答的很快。 | +10 |

## 四、18 位英雄 × 16 职业 的写法模板

每个英雄开一份，**每份 16 段**（一段一个职业）。模板：

```markdown
### 阿喀琉斯 × {职业名}

**t1 初见反应**（这个职业会让他想起什么？）
- 他看到你身上什么：______
- 他说：______
- 三个回答：⊕ 好 / ⊖ 坏 / ∅ 中性

**t2 深入**（他把哪件事说给你听？）
- 三个回答：一条通向 **专属结局**，两条通向 **通用追问**

**专属结局**（只有这个职业能问出来的事）
- 给多少好感：+15 ~ +20
- 结束时的额外效果：回血 / 给牌 / 掉血
```

### 这份表填什么

| 列 | 填什么 |
|----|--------|
| **他看到你身上什么** | 职业的**痕迹**（新娘=婚戒磨痕 / 焚书人=烟味 / 瞎子=看天的角度） |
| **他说** | 一句话点破，不解释 |
| **三个回答** | 顺着问 / 沉默 / 追问原因 |
| **专属结局** | 只有这个职业能触发的**特有分支** |

## 五、写的时候的几条规则

```mermaid
flowchart LR
    A["写之前"] --> B["问自己：<br/>这个职业身上有什么痕迹？"]
    B --> C["让英雄一眼看出来"]
    C --> D["但不解释为什么"]
    D --> E["玩家自己会想：<br/>他怎么知道？"]
```

| 规则 | 说明 |
|------|------|
| **看得见，不解释** | 「你手上有烟味」比「你是焚书的疯子吧」好一百倍 |
| **三层就停** | 初见 → 深入 → 分叉，再深没人记得住 |
| **专属结局要给东西** | 好感 +15 以上，或者回血、给牌 |
| **通用线也要能走完** | 每个话题至少有 1 条路能结束对话 |
| **好感别给太快** | 一个话题最多 +5，专属结局才给 +20 |

## 六、优先级（先写哪几个）

```mermaid
flowchart TD
    P1["⭐⭐⭐ 先写 3 个职业"] --> A["等待丈夫的新娘<br/>（你已经有样例）"]
    P1 --> B["焚书的疯子<br/>（反差最大）"]
    P1 --> C["数星星的瞎子<br/>（和英雄的职业感呼应）"]
    P2["⭐⭐ 再写其余 13 个"] --> D["每个 1~2 天"]
    P3["⭐ 最后 17 × 16"] --> E["批量套模板"]
```

**别一次写 288 段。** 先把阿喀琉斯的 16 个写完，其他英雄会快很多 —— 因为套路已经定了。
