# 十八位英雄 · 关键词与说话底色

> 配合 `HEROES.md`（神话出处 / 现有文案 / NPC 对话数据）使用。
> 这份文件只补三样东西，是写对话时最需要的：
>
> 1. **关键词**（一正一反，写任何一句台词都要能对上）
> 2. **他在《逐神》的世界里是谁**（落到具体的国、具体的年）
> 3. **说话底色**（怎么说话，不是说什么）
>
> 每条都附一句「可用台词」，可以直接进对话。

## 二、逐个的详细补充

### 1. 阿喀琉斯

| 项 | 内容 |
|---|---|
| **关键词** | **荣耀 / 悔过** |
| **在逐神里是谁** | **赫兰 · 灰隼王朝第一骑士**。名字在《灰隼律》扉页 |
| **他做成了什么** | 白银战争前一个人守住了一座桥 |
| **他没做成什么** | **没能救下替他挡箭的朋友** |
| **他说错的话** | 「我宁可短命而被人记住。」（**他确实短命，也确实被记住了**） |
| **说话底色** | **骄傲但不快乐**。谈荣誉的时候会突然沉默 |
| **可用台词** | 「你要记住我。**不是因为我说过什么，是因为我最后没说话。**」 |

### 2. 赫克托耳

| 项 | 内容 |
|---|---|
| **关键词** | **守城 / 明知必败** |
| **在逐神里是谁** | **北马克 · 第七哨塔最后一任守将**，名字叫**奥斯温** |
| **他做成了什么** | 304 年长城被放弃，他守到最后一夜 |
| **他没做成什么** | **没人通知他撤退**（或他收到了，选择不撤） |
| **他说错的话** | 「城在人在。」（**这句话让三十个人陪他留在塔里**） |
| **说话底色** | **平静地交代后事**。不说「守」，只说「还没走」 |
| **可用台词** | 「不是守。**只是还没有走。**」 |

### 3. 奥德修斯

| 项 | 内容 |
|---|---|
| **关键词** | **回家 / 谎言** |
| **在逐神里是谁** | **卡斯提 · 从无声之地活着回来的人**。名字：**伊诺** |
| **他做成了什么** | 走了二十年活着回来——**这是极少数** |
| **他没做成什么** | **回来的时候家里已经没人了**。他在门口站了三天 |
| **他说错的话** | 「等我回来。」（**说了二十年**） |
| **说话底色** | **说很多话，但没有一句是真的**。撒谎是为了让别人不难受 |
| **可用台词** | 「我回来过很多次。**每次都不是这里。**」 |

### 4. 赫拉克勒斯

| 项 | 内容 |
|---|---|
| **关键词** | **力 / 赎罪** |
| **在逐神里是谁** | **赫兰 · 一个替别人做完十二件事的人**。他不是英雄，是**苦役** |
| **他做成了什么** | 十二件事全做完了。**每一件都是别人让他做的** |
| **他没做成什么** | **他没有一件事是为自己做的** |
| **他说错的话** | 「做完这件就完了。」（**他说了十二次**） |
| **说话底色** | **只谈活，不谈苦**。抱怨的话都咽回去 |
| **可用台词** | 「做完这件就完了。**……这话我说过十二次。**」 |

### 5. 珀尔修斯

| 项 | 内容 |
|---|---|
| **关键词** | **斩妖 / 被利用** |
| **在逐神里是谁** | **北马克 · 一个替教会去长城外斩「东西」的猎手** |
| **他做成了什么** | 斩过三个。教会给他记了功 |
| **他没做成什么** | **他斩的东西里，有一个是跑出来的「树上的人」** |
| **他说错的话** | 「我看清了它是什么。」（**他没看清，他只看见了它像什么**） |
| **说话底色** | **短句，像报告** |
| **可用台词** | 「它不像人。**但它一直在看人。**」 |

### 6. 忒修斯

| 项 | 内容 |
|---|---|

| **他做成了什么** | 继承了。没搞砸 |
| **他没做成什么** | **他忘了一件事：换帆**（回来的时候忘了把黑帆换成白帆，父亲看见黑帆就跳了海） |

| **说话底色** | **爱提父亲**。所有事都能挂到父亲身上 |
| **可用台词** | 「我父亲那时候……**算了。**」 |

## 四、英雄与教皇的关系

| 英雄 | 教会怎么处理他的记忆 |
|---|---|
| **阿喀琉斯** | **追认为圣徒** —— 教会需要一个英雄 |
| **赫克托耳** | 宣布「失踪」——「守到最后」不符合教会的叙事 |
| **奥德修斯** | 无记录 |
| **赫拉克勒斯** | 改写成「受神试炼的圣徒」，删掉「替人做」的部分 |
| **珀尔修斯** | **记功** —— 因为他斩的东西是教会让他斩的 |
| **忒修斯** | 无记录 |
| **伊阿宋** | 记成「战争的英雄」，不记背弃 |
| **俄耳甫斯** | **教会的资产** —— 唱诗班以他为名 |
| **卡珊德拉** | 说她「被神惩罚」，不是先知是疯子 |
| **美狄亚** | **禁书** —— 他的名字不能提 |
| **阿塔兰忒** | 无记录 |
| **普罗米修斯** | **关在地下三层，还在那儿** |
| **西西弗斯** | 无记录 |
| **齐格弗里德** | **名字被抹去**，只剩赫拉尔 |
| **布伦希尔德** | 无记录 |
| **洛基** | **教会说白塔失火是雷劈的** —— 否认有人纵火 |
| **海姆达尔** | 无记录 —— 因为「看见」本身就是罪 |
| **提尔** | **追认为圣徒** —— 教会喜欢「献手」这个故事 |

## 五、一条隐藏线索

**十八个英雄，只有三个被教会记住了：阿喀琉斯、珀尔修斯、提尔。**

其余的，要么无记录，要么被改名，要么被关着。

> 「历史不是谁做过什么，是**谁有资格记录**。」
> —— 教皇，512 年
