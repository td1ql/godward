# 五国兴衰年表

> `HISTORY.md` 是**整条主线**（以赫兰为主）。
> 这份文件是**五个国家各自的命**。
>
> 对照阅读：同一年，五个地方在发生五件不同的事。

---

## 一、五国寿命对照

| 国 | 起 | 终 | 活了多少年 | 怎么结束的 |
|---|---|---|---|---|
| **赫兰** | 0 | 420 | **420 年**（中间换了三个朝代） | 变成伪神国 |
| **北马克** | 0 | **304** | **304 年** | 长城被放弃，之后各自为政，**没有「结束」，只是不再是一个整体** |
| **卡斯提** | 42 | **580** | **538 年** | 被教会接管，改称「圣港」 |
| **三渠** | 68 | **318** | **250 年** | 三城之乱被镇压，**之后只剩三座城，没有「盟」** |
| **无声之地** | —— | —— | **没有起点，也没有终点** | **从来没有「兴」，所以也没有「衰」** |

## 二、赫兰（0 ~ 420）

> 主线国家。详细编年看 `HISTORY.md`。这里只标**转折点**。

| 年 | 事 | 性质 |
|---|---|---|
| **0** | 赫拉尔杀神使，建国 | **立** |
| **12~170** | 白塔 / 长城 / 驿站 / 法典 / 白银战争 / 大瘟疫 | **盛** |
| **182** | 老王无嗣，三王并立 | **裂** |
| **198** | 内战结束，最不像国王的人赢了 | **衰之始** |
| **244** | 王座会议成立，王权被架空 | **虚** |
| **260~288** | 大饥荒 / 盗匪 / 白塔失火 / 铁冠王朝亡 | **崩** |
| **288~372** | 王座会议期，八十四年没有王 | **散** |
| **372~415** | 崩解期，最后一道命令无人签署 | **终** |
| **420** | 教皇接管 | **换壳** |

**一句话**：赫兰不是被谁打败的，是**一层层空掉的**。

## 三、北马克（0 ~ 304）

> 二十二个领主。**从来没有真正统一过**，所以也谈不上「灭亡」。

| 年 | 事 | 性质 |
|---|---|---|
| **0** | 落地的人在长城脚下定居 | **立** |
| **40** | 长城合拢（二十二段，接口对不齐） | **盛** |
| **40~150** | 「墙那边的东西」来过三次，都被挡回去 | **守** |
| **150~250** | 各领开始自己修自己那段，**中央不再拨款** | **离** |
| **260** | 大饥荒，冰湖领的粮先断 | **饥** |
| **288** | 赫兰白塔失火，北马克**没有任何反应** | **断** |
| **300** | 教会派人来「登记人数」，被赶走 | **拒** |
| **304** | **长城被放弃。撤退令只送到南边七个哨塔** | **弃** |
| **304 之后** | 二十二个领各自为政，**互相不再称呼对方为「北马克」** | **散** |
| **405** | 星历废止，最后一个星官自瞎 | **盲** |

**一句话**：北马克不是亡了，是**被人忘在北边了**。

**关键细节**：304 年的撤退令**只送到南边七个哨塔**。第七哨塔在最北，**不在名单上**。

## 四、卡斯提（42 ~ 580）

> 从一伙渔民到整个大陆的钱袋，再到教会的仓库。

| 年 | 事 | 性质 |
|---|---|---|
| **42** | 一群渔民和盐贩在海岸定居，立了三块石头当界 | **立** |
| **68** | 设「账房」这个职位 —— **不是市长，是账房** | **定** |
| **105** | 第一份市约《三石约》：**「不问出身，只问付不付」** | **魂** |
| **130~136** | **白银战争**：同时给赫兰和三渠供货，两边都赢了它 | **盛** |
| **152** | 大瘟疫，卡斯提**封港三个月**，死了两千人但保住了城 | **冷** |
| **180~240** | 赫兰内战，卡斯提成了三国所有势力的钱袋 | **极盛** |
| **250** | 第一次「账房危机」：钱借出去了，收不回来 | **虚** |
| **318** | 三渠之乱，卡斯提**拒绝借钱给赫兰镇压** | **断交** |
| **360** | 河决，卡斯提**派船救人**（这是它做过最不像商人的事） | **义** |
| **420** | 教皇接管赫兰。卡斯提**第一个承认**，因为「承认的成本最低」 | **算** |
| **440** | 教会开始在卡斯提「登记」 | **渗** |
| **498** | 「无名者一律视为已死」 —— 卡斯提的码头工**一夜之间全成了死人** | **削** |
| **530~570** | 卡斯提的商船开始给教会运「献祭季」的人 | **堕** |
| **580** | 教会宣布「卡斯提不再是一个市，是一个港口」，改称**圣港** | **吞** |

**一句话**：卡斯提用「不问出身」起家，最后被「无名者视为已死」吞掉。

## 五、三渠（68 ~ 318）

> 三座城共用一条河。**它的兴衰只看一件事：水。**

| 年 | 事 | 性质 |
|---|---|---|
| **68** | 铁桥、盐井、断渠三城立盟，各出一个字，合称「三渠」 | **立** |
| **68~150** | 三城分工：铁桥管桥，盐井管盐，断渠管水 | **和** |
| **150** | 第一次水权纠纷，定下「上游先取」的规矩 | **隐患** |
| **200~280** | 人口增长，上游开始不够用 | **紧** |
| **310** | 断渠在上游修坝 | **裂** |
| **318** | **三城同时造反** —— 因为坝把下游的水截了 | **乱** |
| **318~320** | 赫兰镇压，两年。**三渠死了四万人** | **血** |
| **320** | 坝被拆了，但**没有人敢再提「坝」这个字** | **禁** |
| **330~360** | 三城还在，但**不再互称「同盟」** | **散** |
| **360** | **河决**，三个县被淹（**坝拆了，河道改不回来**） | **报** |
| **381** | 哑者起义，三天被平 | **哑** |
| **420 之后** | 三渠并入教会辖区，三座城各自被改名 | **没** |

**一句话**：三渠的命在一条河上，**河改了道，它就没有了**。

**关键细节**：318 年拆了坝，360 年河决 —— **拆坝不是解决，只是把灾难推迟了四十二年**。

## 六、无声之地（没有年表）

> **它没有兴衰，因为没有人替它记录。**

| 时期 | 发生了什么 |
|---|---|
| **元前 ~ 落地** | 人从树上掉下来，**掉到最西边的那批人** 没有落地——他们掉进了更深的地方 |
| **0 ~ 300** | 有人往西走，**不回来** |
| **300 ~ 400** | 教会开始把「不听话的人」往西边送 |
| **420 ~ 500** | 教会正式把这里定为**「献祭季」的来源地**，因为「这里的人不算人」 |
| **500 ~ 800** | 一直如此。**没有人记录，所以也没有人知道** |

**唯一的一份记录**：教会的一本账，标题是《**无名之地的年入**》。

## 八、五国的「最后一刻」

| 国 | 最后一刻 | 那一刻谁在 |
|---|---|---|

## 九、一句话总结五国

| 国 | 一句话 |
