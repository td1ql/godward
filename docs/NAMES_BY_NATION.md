# 五国人名簿

> 写故事时直接从这里取名字。
> 命名规则见 `NAMES.md` 第九节：**人名欧洲音译，绰号中文意译。**

---

## 使用说明

| 记号 | 含义 |
|---|---|
| **粗体** | 有名有姓、可以当主角的人 |
| 普通 | 有名无姓、可以当配角的人 |
| 括号里的 | 绰号 / 别人怎么叫他 |

**每个国家 4 组**：贵族 / 士兵 / 商人 / 平民 · 圣徒

## 八、命名注意事项

1. **同一国的人名不要撞车** —— 赫兰人名字长（阿尔布雷希特），北马克人名字短（托克）
2. **女名要能一眼看出是女名** —— 结尾多为 -a / -e / -d / -德
3. **绰号一律用中文意译** —— 铁眉 / 桥 / 老萨尔
4. **无声之地的人不给名字** —— 这是设定，不是偷懒
5. **教皇只有一个** —— 不要再造第二个「教皇」
