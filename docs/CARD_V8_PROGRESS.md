## 二、固定流程

1. 定卡名（毒系 16 张已齐，旅途 6 张已齐，斩系做了 3 张）。
2. 一次出 6 个不同动作 → 出对照图 `sheet_*.png` 给用户挑。
3. 用户选编号；不满意就「再来一轮」换动作，或用草图引导改细节。
4. 通过后 `to_game()` 落盘 512×288，`mock_card.py` 出实机卡面图。
5. 每 20~25 张做一次提交。

## 三、本轮沉淀的技巧

| 问题 | 办法 | 工具 |
|------|------|------|
| 飘带 / 包裹 / 骨髅 / 刀光这些道具画不出 | 先画草图，再 img2img（denoise 0.45~0.7） | `sketch_ribbon.py` / `sketch_pack.py` / `sketch_skull.py` / `sketch_guillotine.py` |
| 雾不够浓 | 后期叠多尺度噪声灰雾，脸周围加遮罩 | `fog_overlay.py` |
| 手指数目不对 | 负面词补 `missing thumb / four fingers`，1024×576 出图 | `gen_card_art_v8.py` |
| 左右手 / 姿势要保 | img2img 底图 + denoise 0.45 | `gen_card_art_v8.py --init` |
| 想换脸 | 提高 denoise 到 0.7~0.8 | 同上 |
| 道具消失 | 把道具写进前景（close view），或干脆换成符号图 | — |

## 四、已知画不出的东西（别再硬试）

- **断头台**：三轮都失败（木架 / 十字架 / 画架）。
- **绷带**：会变成木条。
- **獠牙、长飘带**：纯提示词无效，只能草图引导。
- **「剑上滴毒液」这类小水滴**：832/1024 下不画。
